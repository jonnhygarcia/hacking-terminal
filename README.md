# Hacking Terminal FVTT

Un módulo de **Foundry Virtual Tabletop** diseñado para mejorar la experiencia de juego de rol proporcionando una terminal de hacking interactiva.

## 🎮 Características

- **Terminal de Hacking Interactiva**: Simula un sistema de hacking auténtico para campañas de ciencia ficción
- **Interfaz Inmersiva**: Diseño futurista y personalizable
- **Integración con Foundry VTT**: Funciona perfectamente con el sistema base de Foundry
- **Efectos de Sonido y Visuales**: Mejora la atmósfera del juego

## 📋 Requisitos

- [Foundry Virtual Tabletop](https://foundryvtt.com/) v9.0 o superior
- Un navegador web moderno

## 🚀 Instalación

### Método 1: Mediante Foundry
1. En Foundry VTT, ve a **Add-on Modules** → **Install Module**
2. Busca "Hacking Terminal FVTT" o pega esta URL:
   ```
   https://github.com/jonnhygarcia/hacking-terminal_FVTT/releases/latest/download/module.json
   ```
3. Haz clic en **Install**

### Método 2: Manual
1. Descarga el último release desde [Releases](https://github.com/jonnhygarcia/hacking-terminal_FVTT/releases)
2. Extrae la carpeta en `Data/modules/`
3. Reinicia Foundry VTT

## 📖 Uso

1. Activa el módulo en tu mundo de Foundry
2. Los directores de juego pueden acceder a la terminal desde el menú de herramientas
3. Personaliza los parámetros según tu campaña

## 🛠️ Configuración

El módulo incluye las siguientes opciones de configuración:

- **Dificultad del Hacking**: Ajusta la complejidad de los desafíos
- **Estilo Visual**: Elige entre diferentes temas de terminal
- **Sonidos**: Activa/desactiva efectos de audio
